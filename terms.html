第1条（総則）

本利用規約（以下「本規約」といいます）は、株式会社moluta（以下「当社」といいます）が提供するポイ活プラットフォーム「ドロマ」（以下「本サービス」といいます）の利用条件を定めるものです。

ユーザーの皆さまには、本規約に同意いただいた上で本サービスをご利用いただきます。本サービスを利用された時点で、本規約のすべての条項に同意したものとみなします。

第2条（定義）

本規約において使用する用語の定義は、以下のとおりとします。

  1. 「ユーザー」とは、本規約に同意の上、所定の手続きにより本サービスの利用登録を行った個人をいいます。
  2. 「ポイント」とは、当社が本サービス上でユーザーに対し付与する、当社所定の交換先と交換可能なデジタルポイントをいいます。
  3. 「案件」（またはオファー）とは、当社が本サービス上で掲載する、ゲームのプレイその他の条件達成によりポイントが付与される広告案件をいいます。
  4. 「交換先」とは、ポイントと交換可能なPayPay、Amazonギフト券その他当社が指定するサービスをいいます。

第3条（利用登録）

  1. 本サービスの利用を希望する者は、本規約に同意の上、当社の定める方法により利用登録を申請するものとします。
  2. 当社は、以下の場合に利用登録の申請を承認しないことがあります。当社はその理由を開示する義務を負いません。
    • 申請内容に虚偽、誤記または記載漏れがあった場合
    • 過去に本規約に違反したことがある場合
    • 16歳未満である場合
    • 反社会的勢力等に該当すると当社が判断した場合
    • その他、当社が利用登録を適当でないと判断した場合
  3. 16歳以上18歳未満の方は、保護者の同意を得た上で利用登録を行うものとします。

第4条（アカウントの管理）

  1. ユーザーは、自己の責任においてアカウント情報（メールアドレス、パスワード等）を適切に管理するものとします。
  2. ユーザーは、いかなる場合にも、アカウントを第三者に譲渡または貸与し、もしくは第三者と共用することはできません。
  3. アカウント情報の管理不十分、使用上の過誤、第三者の使用等によって生じた損害に関する責任はユーザーが負うものとし、当社は一切の責任を負いません。
  4. ユーザーは、アカウント情報の盗用またはアカウントが第三者に使用されていることが判明した場合には、直ちに当社に通知し、当社の指示に従うものとします。

第5条（サービスの内容）

  1. 本サービスは、ユーザーがゲームのプレイその他当社が定める条件を達成することでポイントを獲得し、当該ポイントを交換先のサービスと交換できるプラットフォームです。
  2. 本サービスはウェブサイトおよびiOSアプリケーションを通じて提供されます。
  3. 本サービスの利用は無料です。ただし、本サービスの利用に必要な通信費、端末購入費用等はユーザーの負担とします。
  4. 案件の内容、ポイント数、達成条件等は、当社の判断により予告なく変更されることがあります。

第6条（ポイント制度）

  1. ポイントは、ユーザーが案件に定められた条件を達成した場合に、当社の定める方法およびタイミングで付与されます。ポイントは無償で付与されるものであり、ユーザーが対価を支払って購入するものではありません。
  2. ポイントは、1ポイント＝1円相当として取り扱われます。
  3. ポイントの有効期限は、最終獲得日または最終交換日のいずれか遅い方から起算して180日間とします。有効期限を経過したポイントは自動的に失効し、復元することはできません。
  4. 以下の場合、ポイントの付与が行われない、または取り消されることがあります。
    • 条件達成が広告主側のシステムで確認できなかった場合
    • 不正な手段により条件を達成したと当社が判断した場合
    • 同一案件に対し複数回の参加が確認された場合
    • ユーザーが案件の参加条件（年齢、地域等）を満たしていなかった場合
  5. ポイントは、法定通貨または暗号資産ではなく、現金と同等の価値を有するものではありません。
  6. ポイントを他のユーザーに譲渡、贈与、相続、売買、質入れ等することはできません。

第7条（ポイントの交換）

  1. ユーザーは、500ポイント以上を保有している場合、当社が指定する交換先にポイントの交換を申請することができます。
  2. 交換手数料は無料とします。ただし、交換先の利用に関して当該交換先のサービス提供者が手数料等を徴収する場合があり、当社はこれについて一切の責任を負いません。
  3. ポイント交換後の取消し、返金、返品は原則としてできません。
  4. 交換先およびその交換レートは、当社の判断により予告なく変更、追加または廃止されることがあります。
  5. 交換の処理には、当社所定の期間を要する場合があります。

第8条（禁止事項）

ユーザーは、本サービスの利用にあたり、以下の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 犯罪行為に関連する行為
  3. 不正な手段によりポイントを取得し、または取得しようとする行為（VPN・エミュレータ・自動操作ツール・BOTの使用、複数アカウントの作成等を含むがこれらに限られない）
  4. 当社または第三者の知的財産権、肖像権、プライバシーその他の権利または利益を侵害する行為
  5. 当社のサーバーまたはネットワークの機能を破壊し、または妨害する行為
  6. 本サービスの運営を妨害するおそれのある行為
  7. 他のユーザーに関する個人情報等を収集または蓄積する行為
  8. 他のユーザーに成りすます行為
  9. 当社のサービスに関連して、反社会的勢力に対して直接的または間接的に利益を供与する行為
  10. 虚偽の情報を登録する行為
  11. アカウントの譲渡、貸与、売買等の行為
  12. リバースエンジニアリング、逆コンパイル、逆アセンブルその他本サービスのソースコードを解析する行為
  13. 当社が許諾しない広告、宣伝、勧誘または営業行為
  14. 面識のない第三者との出会いを目的とした行為
  15. その他、当社が不適切と判断する行為

第9条（利用制限および登録抹消）

  1. 当社は、ユーザーが以下のいずれかに該当する場合には、事前の通知なく、ポイントの全部もしくは一部の無効化、本サービスの利用の全部もしくは一部の制限、またはアカウントの登録抹消を行うことができるものとします。
    • 本規約のいずれかの条項に違反した場合
    • 登録事項に虚偽の事実があることが判明した場合
    • 12か月以上本サービスの利用がない場合
    • 当社からの連絡に対し、相当の期間内に返答がない場合
    • その他、当社が本サービスの利用を適当でないと判断した場合
  2. 前項の措置によりユーザーに生じた損害について、当社は一切の責任を負いません。

第10条（サービスの変更・中断・終了）

  1. 当社は、ユーザーへの事前の通知なくして、本サービスの内容を変更し、または本サービスの提供を中断もしくは終了することができるものとします。
  2. 当社は、以下のいずれかに該当する場合、本サービスの全部または一部の提供を一時中断することができるものとします。
    • 本サービスにかかるシステムの保守点検または更新を行う場合
    • 地震、落雷、火災、停電その他の天災等の不可抗力により本サービスの提供が困難となった場合
    • コンピュータまたは通信回線等が事故により停止した場合
    • その他、当社が本サービスの提供が困難と判断した場合
  3. 当社は、本サービスの提供の中断または終了によりユーザーまたは第三者が被ったいかなる不利益または損害についても、一切の責任を負いません。
  4. 本サービスを終了する場合、当社は30日前までにユーザーに通知するよう努めるものとします。この場合、未交換のポイントについて交換のための合理的な猶予期間を設けます。

第11条（免責事項）

  1. 当社は、本サービスに事実上または法律上の瑕疵（安全性、信頼性、正確性、完全性、有効性、特定の目的への適合性、セキュリティ等に関する欠陥、エラーやバグ、権利侵害等を含みます）がないことを明示的にも黙示的にも保証しておりません。
  2. 当社は、本サービスに起因してユーザーに生じたあらゆる損害について、当社の故意または重過失による場合を除き、一切の責任を負いません。
  3. 当社は、本サービスに関して、ユーザーと他のユーザーまたは第三者との間において生じた取引、連絡または紛争等について一切の責任を負いません。
  4. 当社は、案件に関する広告主のサービスの品質、内容、適法性等について一切保証せず、これらに起因してユーザーに生じた損害について一切の責任を負いません。
  5. 本サービスの利用にあたりユーザーがダウンロードまたはインストールしたゲーム等のアプリケーションに起因する損害について、当社は一切の責任を負いません。

第12条（知的財産権）

  1. 本サービスに関する知的財産権はすべて当社または当社にライセンスを許諾している者に帰属しており、本規約に基づく本サービスの利用許諾は、これらの知的財産権の使用許諾を意味するものではありません。
  2. ユーザーは、当社の事前の書面による承諾なく、本サービスに関するコンテンツを複製、転載、改変、販売その他の二次利用をすることはできません。

第13条（退会）

  1. ユーザーは、当社の定める手続きにより、いつでも本サービスから退会することができます。
  2. 退会した場合、ユーザーが保有するすべてのポイントは失効し、以後これを使用することはできません。退会後のポイントの復元には一切応じかねます。
  3. 退会後、当社はユーザーに関する情報を、法令に基づき必要な期間保持した後、適切に削除します。

第14条（利用規約の変更）

  1. 当社は、必要と判断した場合には、ユーザーに通知することなくいつでも本規約を変更することができるものとします。ただし、ユーザーに重大な影響を及ぼす変更の場合は、変更の効力発生日の14日前までにユーザーに通知するよう努めます。
  2. 変更後の本規約は、当社ウェブサイトに掲載したときから効力を生じるものとします。
  3. 本規約の変更後に本サービスを利用した場合、ユーザーは変更後の規約に同意したものとみなします。

第15条（通知）

当社からユーザーに対する通知は、本サービス上での掲示、電子メールの送信その他当社が適当と判断する方法により行うものとします。通知は、当社が電子メールで行った場合はメール送信時に、本サービス上で行った場合は掲載時に、それぞれ効力を生じるものとします。

第16条（準拠法・管轄裁判所）

  1. 本規約の解釈にあたっては、日本法を準拠法とします。
  2. 本サービスに関して紛争が生じた場合には、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
